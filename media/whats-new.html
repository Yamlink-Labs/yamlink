0.8.2 · Excel-ification

Your notes just learned to do math.

Type a formula into any note and watch it compute live — no spreadsheet, no separate app, no schema required. Pull a number straight out of another note. Summarize an entire table in one line. Run real finance math — NPV, IRR, compound growth — the same way Excel does it, with the same sign conventions, so nothing you already know has to be relearned. This is the release where Yamlink stopped being just a place you keep notes and became a place you can also work the numbers.

What shipped

All thirty, not a curated highlight reel.

+
35
what this release is all about
Inline calculations
Stop doing the math in your head, or worse, in a separate spreadsheet you'll lose track of. Type `=price*qty` directly in a note and Yamlink computes it live, right there in your text. Every cell gets an automatic label that renumbers itself the instant you insert a new one above it — the same trick a spreadsheet pulls when a row shifts, except you never asked for it and it just works. Hover any formula to see exactly how it got its answer, step by step. And when something's wrong, you get a real reason — #REF!, #DIV/0!, #NAME?, #VALUE! — not a silent wrong number you won't catch until it costs you something. Autocomplete opens the moment you type a formula, the same way [[ already does elsewhere, and now suggests this note's own frontmatter fields and any table's columns right alongside your own cells.
+
12
answer harder questions without leaving the note
Statistics, finance & growth
Twelve functions that turn a list of numbers into an actual answer: the typical price (median), how much it varies (stdev), whether a purchase pays for itself (npv, irr), what a loan costs per month (pmt), how fast something is really growing (cagr). Same formulas Excel uses, same sign conventions — if you already think in spreadsheet terms, nothing here needs translating. Deadlines get the same treatment: today(), days_between(), and a real if() that only ever evaluates the branch it takes.
+
4
no second query needed
Table & cross-note ranges
The most common spreadsheet habit — copying a number from one place into another — is gone. sum([[budget]]^Y1:Y5) reaches straight into another note's cells. sum(T1.budget) reads an entire column out of this note's own table. Name a range once (prices=Y1:Y8) and reuse it in median, sumif, countif, anywhere a list belongs. Nothing to retype, nothing to keep in sync by hand.
+
two new ways to see your vault
Line & Pie charts
Two more ways to see your data at a glance — and a Value picker so Bar and Pie can chart a real total instead of a plain count, no extra query required.
+
one number, many ways to slice it
Summarizing across notes
One query, every answer you need. aggregate sum()/average()/min()/max()/count totals, averages, and counts across an entire matched set — standalone, or one line per group by bucket. Add when priority = high and you get the high-priority total right next to the overall one, in the same breath.
+
fixes
x-graph physics & honesty
Dragging a node no longer sets off a chain reaction across the whole graph. Clusters look like clusters, not a crystal lattice. Every type gets its own real color. And when the view is only showing you part of the vault, it finally says so — "128 of 340 notes" instead of quietly pretending that's everything.
+
formatting without touching the real value
Display formats
as currency, as percent, as comma — control how a number looks without ever touching the number itself, so the math underneath stays exact.
Group labels, fixed
group by on a linked field now shows the note's name, not raw [[brackets]].
Hover finds what you meant
Accent-insensitive matching, plus a fallback that finds the real paragraph when there's no heading to land on.
Booleans in parentheses
(total > 1000) and (count < 5) — grouping finally works on comparisons, not just arithmetic.
No more nagging yourself
Accept a field suggestion and Yamlink won't immediately suggest the same one right back.
sort asc, actually works
Writing it explicitly used to silently drop the whole clause. Fixed.
Link fix goes to the right field
The quickfix now writes into the field you invoked it from, not a hardcoded one.
Autocomplete that's learned something
Suggests formula shapes already proven out in other notes of the same type.
30 shipped · 2 deferred on purpose (percentile/correl need a shape this evaluator can't express yet) · 1 formula engine, 5 surfaces reading from it
How this cycle actually went

As I've said endlessly since I started working on Yamlink, "I just want something to suit my needs." Well, 0.8.2 is exactly that.

I recently started my MBA, and I am now neck deep into statistics, projections, finances, and long equations calculating long-term variable interest. And I wanted that in my MD. And then I said, well, what if Yamlink and Excel had a wild fling?

Have "cell-like" behavior for your calculations, reference results all over your notes, and better yet, query them and view graphical output of your work. I thought this could give Yamlink a whole new outlook and open the door to a whole new set of applications.

Initially, I just wanted to view formulas and calculations, and it just kept growing and growing. Now, you can literally handle things like your own personal finances.

In essence, Yamlink is now your own local, computation engine living in your MD. Your notes and all your numbers live side by side, and that's a pretty cool thing if you ask me.

Insights

I've wanted a Zed extension for a long time. Being editor-agnostic was the whole point of building Yamlink's LSP server in the first place — hover, completions, rename, diagnostics, all of it already speaks the same protocol Zed would need. Living outside of VS Code, opening the way for a potential app, that was always the goal.

Between starting my MBA and everything else already going on (work, family), there's no resources for a proper Zed extension. As an alternative: if you want to run Yamlink outside VS Code in the meantime, it already works in Cursor — I've tested it directly. There's no packaged install for it yet, since the time's gone into the VS Code extension and the desktop app instead, but if enough of you want a downloadable Cursor package up on the Yamlink GitHub, that's something I can do. You can comment on our GH discussion thread or comment on our Yamlink Labs X page if you want.

— J

Coming next
Mathematical depth (tentatively)
Next up, I want the graph and the intelligence layer to get genuinely smarter, not just bigger. That means noticing which notes actually belong together instead of just matching identical fields, spotting the handful of notes that quietly bridge two otherwise separate parts of your vault, and finding the vault's real structural core rather than just its most-linked notes. The graph's layout should also start behaving like a real physical system, so clusters settle into place on their own instead of needing a synthetic nudge. And I want to close the one rough edge from this release — T<N> table labels will get the same automatic renumbering Y<N> cell labels already have.
