# Start Here

Use this vault like a live product walkthrough.

## First Tour

1. Open [command-hub](dashboards/command-hub.md) and run the `!view` blocks.
2. Open [war-briefing](dashboards/war-briefing.md) and compare it with the more operational `command-hub`.
3. Open [johnny-rico](characters/johnny-rico.md) and inspect Note Report.
4. Open [rasczaks-roughnecks](units/rasczaks-roughnecks.md) and inspect incoming links.
5. Open [planet-p-assault](missions/planet-p-assault.md) to see mission structure, linked entities, and dated tasks.
6. Open Calendar and look at activity around `2297-06-10`, `2297-08-12`, `2297-09-21`, `2297-10-03`, and `2297-10-10`.
7. Open Vault Health and look for the intentionally incomplete sandbox note.

## Try These Flows

- Create a new character or mission from the existing structures.
- Add a new briefing note using the `mission` template.
- Open Query Builder from [command-hub](dashboards/command-hub.md) and build a character or mission view.
- Try frontmatter completion inside an empty `unit:` or `commander:` field.
- Open [intel-gaps.md](notes/intel-gaps.md) and inspect how a plain note still threads into the operational graph.
