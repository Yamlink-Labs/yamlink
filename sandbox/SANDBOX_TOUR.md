# Sandbox Tour

This vault is shaped to show a compact Yamlink operating system in a fictional military / intelligence setting:

- `characters/`
  - personnel, officers, and specialists
- `units/`
  - mobile infantry or fleet structures
- `missions/`
  - dated operations with tasks and follow-ups
- `campaigns/`
  - multi-note arcs with related views
- `dashboards/`
  - entry surfaces with `!view` examples
- `notes/`
  - intelligence, support material, and one drift example

The sandbox also now includes tags, quoted evidence blocks, footnote references, and heading-targeted wikilinks so users can test more than frontmatter alone.
