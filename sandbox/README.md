# Yamlink Sandbox

`Yamlink Sandbox` is a real sample Yamlink vault you can open in VS Code and explore.

This version is themed as a Starship Troopers-style operational knowledge vault so it can be shared publicly while still showing that Yamlink adapts cleanly to non-business structures.

What this vault is for:

- learning Yamlink by using a working vault instead of only reading docs
- inspecting smart templates, linked frontmatter, note report, calendar, and query examples
- seeing the same Yamlink engine operate on characters, units, missions, and campaigns instead of CRM entities

Suggested path:

1. Open [START_HERE.md](START_HERE.md)
2. Open [dashboards/command-hub.md](dashboards/command-hub.md)
3. Compare it with [dashboards/war-briefing.md](dashboards/war-briefing.md)
4. Inspect [characters/johnny-rico.md](characters/johnny-rico.md)
5. Inspect [missions/planet-p-assault.md](missions/planet-p-assault.md)
6. Open Calendar, Note Report, and Vault Health

This sample vault includes:

- `_templates/` for core note types
- characters, units, missions, campaigns, dashboards, and supporting notes
- linked frontmatter and body relations
- tasks and dated activity for Calendar
- `!view` examples for dashboards and campaigns
- one intentionally incomplete note so Vault Health has something to surface
