# Field Debrief Pattern

Use short recaps, explicit next actions, and linked entities in the note body so Yamlink can connect context across characters, units, missions, and campaigns.

## Example Pattern

- mention the unit like [[rasczaks-roughnecks]]
- mention the character like [[johnny-rico]]
- mention the mission like [[planet-p-assault]]
